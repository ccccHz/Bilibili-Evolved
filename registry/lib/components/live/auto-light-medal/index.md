# 当前房间自动点亮粉丝牌

进入可见的直播间后，检查你是否持有该房间的粉丝牌。仅在**房间正在直播、勋章熄灭且服务端提供免费点赞任务**时，通过原生点赞按钮完成任务，然后重新检查点亮结果。

- 已点亮、没有牌子、未开播或状态不明确时跳过。
- 尊重原生点赞冷却，最多尝试 30 次；任务有已完成进度时只补剩余次数。
- 同一账号、同一房间每天最多自动尝试一次，并协调同源标签页避免同时执行。
- 换房、页面转入后台、关闭组件或点击“停止本次”会停止后续点击；已点击的点赞可能稍后由原生页面上报。
- 不赠礼、不付费、不发送弹幕，不遍历其他房间。

组件详情显示状态和点击进度。“重新检查”可以重新读取状态，但不会绕过当天的尝试限制。未确认点亮时停止，不会无限补赞。

默认关闭，开启后生效。此组件与旧的“一键点亮直播间粉丝勋章”独立，建议使用此组件，不同时启用其他自动点赞脚本。
